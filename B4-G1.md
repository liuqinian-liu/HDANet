# B4+G1 in HDANet

This implementation reproduces the FSSD-12 1-shot, seed 2025 B4+G1 experiment. B4 adds the CSH output boundary consistency loss with weight 0.1. G1 adds a PDM-guided spatial gate to each AEM branch. Both are off by default in the existing HDANet configuration.

## Three fold configurations

| Fold | Model | Epochs | Batch | Learning rate | Original experiment |
| --- | --- | ---: | ---: | ---: | --- |
| 0 | no ASPP | 200 | 2 | 0.001 | `fssd12_b4_m2_g1_three_arm_20261010/B4_G1_fold0` |
| 1 | ASPP | 200 | 2 | 0.0025 | `fssd12_b4_combinations_fold1_20261009/B4_G1` |
| 2 | ASPP | 300 | 4 | 0.0025 | `fssd12_b4_m2_g1_three_arm_20261010/B4_G1_fold2` |

The configs in `config/B4-G1` preserve the trained settings. Their dataset list and output paths are relative to the repository; set `DATA.data_root` to the local FSSD-12 directory. The listed folds have the same SHA-256 data-list hashes as the audited snapshots. The FSSD-12 dataset is not included. The local code handoff includes the existing ImageNet `initmodel/resnet50_v2.pth`; the GitHub repository already tracks that file, so this change does not upload it again.

From the repository root, run `python train_b4_g1.py --config config/B4-G1/fold0.yaml` (use fold1 or fold2 as needed). Then run `python evaluate_b4_g1.py --config config/B4-G1/fold0.yaml` for the selected checkpoint, or append `--disable-spatial-gate` for a same-checkpoint G1 diagnostic. Existing `train-fssd12-fold*.py` and other dataset entry points keep their original behavior.

The implementation follows the fold0/2 `code_g1` snapshot. In the fold1 source, extra spectral A/B/C switches were disabled for `B4_G1`; its active B4/G1 model is equivalent. `FEM.py` retains the finite denominator guard from the trained snapshot. The G1 gate class, bounds, seed isolation, B4 loss, and training/evaluation logic are preserved. Only path normalization and removal of unused experimental options differ.

Historical results are validation scores from checkpoints selected on that same validation set. They are not independent test results or a multi-seed estimate. See [results/B4-G1](results/B4-G1/README.md) for exact files, hashes, and the Release archives.
